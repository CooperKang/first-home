# 첫 집 계산기

사회초년생·생애최초·신혼부부를 위한 첫 집 계산기입니다. <https://cooperkang.github.io/first-home/>

소득과 모은 돈, 지금 갚고 있는 대출을 한 번 넣으면 모든 계산기가 같이 씁니다. 입력값은 브라우저(localStorage)에만 저장됩니다.

- **살 수 있는 집**: LTV, 수도권·규제지역 집값별 상한(6억·4억·2억), 스트레스 DSR, 장래소득, 정책 대출(디딤돌·신혼·신생아 특례·보금자리론)을 모두 따져 살 수 있는 가장 비싼 집을 찾고, 취득세·지방교육세·중개보수·법무사비·국민주택채권·인지세·이사비까지 통장 거래내역처럼 보여 줍니다. 처음이라 놓치기 쉬운 것(전입 의무, 실거주 의무, 신용대출이 한도를 깎는 정도, 주기형 금리로 바꾸면 늘어나는 한도, 혼인·출산 증여 공제 등)을 입력값에 맞춰 골라 줍니다.
- **DSR·대출 한도**: 기존 대출 종류별 DSR 반영 방식, 스트레스 금리 포함/제외 DSR, 장래소득 계산기
- **몇 년 뒤 내 집**: 월 저축액·수익률·연봉 인상률·집값 상승률로 해마다 살 수 있는 집값과 목표에 닿는 해, 목표 시점별 필요 월 저축액
- **전세·월세**: 은행·버팀목·청년·신혼 전세대출 비교, 한 달 실제 비용, 전월세 전환, 깡통전세(전세가율)·HUG 보증 가입 점검, 계약 순서별 체크리스트
- **분양·청약 자금**: 계약금·중도금 일정, 이자후불제 이자, 입주 때 잔금대출 재심사와 세금
- **규제·정책**: 6·27부터 8·13까지 바뀐 대출 규제, 내 상황에 적용되는 기준, 용어 풀이
- **가족 도움(증여·차용)**: 증여받을 돈과 가족에게 빌릴 돈을 넣으면 쓸 수 있는 돈에 더해 계산합니다. 증여재산공제(성인 5천만원, 혼인·출산 1억원)와 증여세, 가족 차용의 최소 이자율(적정 이자율 4.6%, 연 1천만원 기준)과 통장에 찍혀야 할 월 이자, 차용증 실전 팁을 보여 줍니다.

매물은 네이버 부동산 매물지도를 동네·집 종류·가격대 조건을 넣은 주소로 바로 엽니다(`src/calc/naver.ts`). 호갱노노·KB부동산·직방 등도 연결합니다.

## 개발

```sh
npm install
npm run dev      # http://localhost:5173
npm test
npm run build
```

## 규제 값 고치기

규제·세율·정책 대출 숫자는 모두 `src/calc/policy.ts` 한곳에 있습니다(기준일 `POLICY_AS_OF`). 계산 로직은 `src/calc/`에 있고 `src/calc/calc.test.ts`가 검증합니다.

| 항목 | 기준 |
|---|---|
| LTV·집값별 주담대 상한 | 6·27, 9·7, 10·15 대책 |
| 스트레스 금리 | 3단계 1.5%p, 수도권·규제지역 하한 3.0%p, 지방 0.75%p(2026.12.31까지) |
| 장래소득 비율 | 은행연합회 모범규준, 2024년 고용노동통계(부동산계산기.com 표) |
| DSR 부채 산정 | 금융위원회 DSR 기준(신용대출 5년, 카드론 3년, 전세대출 제외 등) |
| 취득세·중개보수·국민주택채권 | 지방세법, 공인중개사법 시행규칙, 주택도시기금법 |

정책 대출 금리·한도는 자주 바뀌어서 화면에 범위로 보여 주고 공식 사이트로 연결합니다. 결과는 참고용이며 실제 한도와 금리는 금융회사 심사로 정해집니다.

참고한 계산 방식: [부동산계산기.com](https://xn--989a00af8jnslv3dba.com/)의 DSR·LTV·장래소득·취득세 계산기
